# Bundled text font

XinYu uses **Noto Sans SC**, an unmodified variable TrueType font, for Chinese,
Latin text and numbers on Windows and Android. Its `wght` axis supports 100–900.
Body text uses 400; interface headings and selected labels use 500. Sticker
illustrations retain their heavier lettering. Emoji and characters absent from
this font fall back to the operating system.

The complete font is bundled, rather than a subset of the interface strings, so
user-written conversations and names are not restricted to the preview text.
No font download is needed when the application starts. The file adds 17,772,300
uncompressed bytes; each weight uses the same asset.
