# Android 0.2.8：回到底部按钮常驻

日期：2026-09-26。用户反馈找不到快速回到聊天底部的按钮。

## 原因与修正

旧版仅在滚动偏移达到 100 像素、follow 变为 false 时显示按钮，空白会话也没有入口。
轻微上翻仍被当作已经在底部，会把阅读位置保存为 0，并可能被后续回复带回底部。
这是源码和测试确认的显示条件；没有连接用户的红米 K50，不能据此断言其已安装版本。

- 按钮固定在输入框上方右侧，独立占位，不盖住聊天文字或输入框。
- 胶囊形玻璃按钮常驻；空白会话显示但置灰，有消息后启用。无新消息时显示“回到底部”，
  上翻期间有新回复时显示新消息数量，点击后恢复“回到底部”。
- 底部判定只容忍 2 个逻辑像素的布局误差，并统一控制器、位置恢复和滚动监听的判断。
  监听只接收聊天列表本身的竖向滚动，忽略内部控件的滚动通知。
- 保留主动发送自动下滑、上翻时不抢阅读位置、草稿、锚点与重启恢复。
