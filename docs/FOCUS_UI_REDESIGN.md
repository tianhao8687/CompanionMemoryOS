## 视觉与实现

画面铺满整个应用内容区域，采用雾蓝暮色、淡粉云光和宁静湖面。
画面中心依次是当前头像、名字、陪伴文案、可选任务、计时和两个主要操作。
无外层弹窗、内嵌房间或仪表盘卡片。背景为独立生成的无文字图片，控件均由 Flutter 渲染。
全屏表示应用内完整页面，不强制操作系统进入无边框模式。

色板为正文 `#253C5B`、次级文字 `#405573`、操作 `#455F83`、默认头像 `#718DB2`、
弹层 `#F3F5FA`。沿用内置 Noto Sans SC 可变字体：陪伴句桌面 38 / 手机 28，字重 300；
计时 68 / 56，字重 200，等宽数字；正文 15，辅助文字 13–14。按钮高度至少 52，顶部触控区至少 48。
默认头像外有轻柔的径向光晕；不播放循环动画或声音，不轮播鼓励语。

主入口为聊天工具区「陪我专注」。未开始时，全屏内填写选填任务和时长；
聊天中的自然语言确认卡保留可编辑表单，明确开始后自动进入全屏。
返回聊天、系统返回或 Esc 保留同一时钟。计时状态决定文案和操作：

| 状态 | 陪伴文案 | 操作 |
| --- | --- | --- |
| 准备 | 留一会儿，我陪你。 | 编辑任务/专注/休息时长，开始 |
| 专注 | 你慢慢来，我在。 | 暂停、结束 |
| 暂停 | 不着急，停一会儿。 | 继续、结束 |
| 到时 | 这段时间，到这里了。 | 休息一下、再加五分钟、先到这里 |
| 休息 | 歇一会儿，我也在。 | 暂停、结束 |
| 结束 | 先到这里，慢慢来。 | 再来一段、留下一点进展 |

记录和提醒设置位于更多菜单；桌面另有活动记录图标。进展仍只在用户主动填写和保存后写入记忆。

## 概念与最终渲染对照

本轮先生成完整概念，再生成独立无文字背景，随后实现原生页面。
概念由代理按用户要求选用，没有将其表述为用户已批准。

- 原尺寸最终渲染：同目录 `flutter-focus-1536.png`（1536×1024）。
- 其他主视图：`flutter-focus-{320,390,768,1024,1440}.png`。
- 状态渲染：`flutter-focus-{setup,paused,arrived,rest,ended}-390.png`。
- 生产素材：`clients/xinyu_flutter/assets/focus/blue-hour.png`，已注册在 pubspec 并随原生构建打包。

已使用 `view_image` 在同一轮检查中查看概念与最终 Flutter 渲染。
截图来自真实组件树、内置中文字体和真实原生控件，数据使用合成仓库。
Browser/IAB 不能承载 Windows 原生 Flutter 界面，因此本轮采用组件渲染及 Windows 构建；
没有用网页截图代替原生界面，也没有将窄屏渲染当作 Android 真机验收。

| 对照点 | 概念证据与实际渲染 | 修正或有意差异 |
| --- | --- | --- |
| 全屏构图 | 概念无外框；实际 Scaffold 覆盖整个视口，头像/文案/时钟居中 | 从小窝弹窗中完全拆出；六档宽度断言页面边界与视口一致 |
| 背景与色彩 | 暮色云光、远山、湖面与底部草叶 | 单独导出无 UI 的背景，保留原色，不添加全屏染色层；手机中心裁切 |
| 字体 | 概念轻量标题和计时；实际 Noto Sans SC 300/200 与等宽数字 | 概念生成的标题带宋体特征，实际有意沿用项目内置无衬线字体；修复时长选项漏设中文字族 |
| 头像 | 概念为圆形文字头像，实际使用现有图片加载器 | 测试无自定义图片时显示“禾”；真实设置有图时复用该图，光晕以渐变绘制，避免测试阴影呈硬边 |
| 导航与图标 | 返回聊天、陪伴专注、历史、更多 | 图标使用项目 Material 族；导航改为深色以保证天空上的可读性，手机返回文字收为带 tooltip 图标 |
| 按钮与留白 | 两个水平主要操作，正文与操作之间留白 | 修正 320px 普通字号按钮挤成两行；大字号保留自然换行及整页滚动，不缩小系统文字 |
| 首屏文案 | 角色名、陪伴句、任务、时钟、时长、暂停/结束 | 对照差异仅为真实名字/任务/时间；概念 24:38 替换为测试当前 30:00，无新增营销文案 |
| 其他状态 | 概念为运行态，实际扩展准备、暂停、到时、休息及结束 | 延续同一色板、头像、布局；状态文案和对应按钮见上表，不把计时完成当成任务完成 |

原尺寸和六种宽度均已检查。除上述字体、导航色、原生图标和响应式裁切等明确差异外，
整体构图、图像风格、层级及文案已按选用概念核对；未遗留裁切、乱码、按钮不可达或明显布局偏差。

- 交互：确认前不计时、聊天卡确认后进入全屏、软键盘避让、返回后同一时钟、Esc、暂停/继续、
  到时加五分钟、进入和暂停休息、提前结束、主动保存原话进展、再次开始、提醒开关与历史。
