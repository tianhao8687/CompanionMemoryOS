# 保留个性与正常冲突：修改和真实对话复测

2026-09-25。当前程序已应用新的聊天规则和林舟自定义风格。目标是让人物有连续的偏好、
情绪和立场，容得下争辩、暂时谈不拢，也容得下真心赞同、改变主意和道歉。
本轮不把温柔程度、回复长短、问号数量或立即和解作为男友感的通过标准。

## 生效的修改

- 公共相处规则允许有缘由的不满、反问、拌嘴、吃醋和短暂僵持。道歉针对具体失言，
  可以保留原来的立场；同样不要求为了表现主见而反对对方。
- 默认人物配置从 `0.1.5` 更新为 `0.1.6`，去掉分歧中必须平和、每轮给出安排等暗示。
  编译后的提示明确区分硬规则与可以随人物、语境调整的软倾向。
- 温柔、活泼、沉稳三个预设各自补足不同的在意点和表达方式，不统一变成强硬口吻。
- 当前“林舟”保留此前公开男友提示词适配版的热情和亲密，中文部分改为热情、爱闹、
  有点嘴硬，重视承诺，也有自己的步调。示例包括口味不同、真心赞同、具体道歉和未和解的暂停。
  这些是表达倾向和虚构示例，不是必须完成的动作清单或真实共同经历。
- 新增可重复运行的 [20 轮人物场景](../tests/scenarios/personality_quality.json)，
  并在 [测试文档](CHAT_QUALITY_TESTING.md#个性与关系冲突的人工评审)登记人工评审标准。
  场景标准只供评审，测试不会把预期答案或评语发给聊天模型。

当前程序只改了 `custom_style` 设置；模型、温度、thinking、记忆配置、主动关心设置和
其他用户设置均保留。没有字数或问题配额，也没有后处理删改模型原始回复。

## 一处影响人物连续性的实际缺陷

真实 trace 显示，某些上一轮的 assistant 回复虽然仍保存在会话中，却没有传给下一轮模型。
原因是检索系统把它判为不适合用来证明事实的低置信度旧话，`suppress` 又被同时用于
过滤近期对话。于是模型能看到用户前后说了什么，却看不到自己刚才给过什么回答。
本轮复现定位的是检索用途混淆，不是放开现实/虚构分层。

修复为带用途的决定：仅当同一完整会话作用域里的 assistant 旧话因普通检索抑制而被过滤、
且没有用户禁止引用或来源链限制时，标记为 `retrieved_evidence`。它仍不能作为检索事实，
但可以以 assistant 身份保留在近期对话里。其余决定默认 `all_context`，旧记录也保持这个默认。
删除、同意、敏感内容、用户反馈、来源依赖、过时事实和现实层筛选仍独立生效。

新增回归先复现上一条回复丢失，再验证保留、禁止引用、删除来源、用户证据及跨会话限制。
初版测试夹具字段不完整的失败记录也保留，没有把它当作产品缺陷证据。

| 实际模型输入检查 | 上下文完整的续聊轮数 |
|---|---:|
| 修改前 A | 2 / 8 |
| 只调整人物后的 B | 6 / 12 |
| 修复对话保留后的 C | 12 / 12 |

这里的“完整”仅表示这些短对话中，之前的 assistant 轮次全部按顺序传入；
不是语言质量分数，也不表示所有历史都应绕过隐私、遗忘和上下文预算。

## 真实模型批次

沿用 `deepseek-flash`、temperature 0.9、thinking enabled，单次输出最多 4096 token。
每批使用真实应用进程、同一 HTTP/存储/上下文/模型路径和新建合成数据库。
只把隔离实例的向量后端设为 off、主动关心关闭；没有读取或复制日常数据库。
Key 从当前安装的 Windows 凭据管理器通过父进程环境提供，没有写入命令参数或设置文件。

单独产生确定改善，不能作为官方测试库得分，也不是盲评。全部原始对话和失败均保留。

## 从虚构成年女性“小雨”的角度读最终对话

这是一个角色的相处体验，不代表所有女性。

| 场景 | 具体观察与判断 |
|---|---|
| 音乐会与在家看综艺 | 先争取想去的活动，受到质疑后没有立刻全盘认错；得知对方连续工作很累后愿意改变安排，仍保留对音乐会的兴趣。这个变化有理由。反问本身不扣分；但断言对方想要什么样的伴侣，仍属于替对方下定义。 |
| 被临时推迟两次约定 | 不高兴有具体原因，被说计较时继续强调提前说明；对方请求独处后停止争论，没有硬说已经翻篇。符合有情绪、有立场的相处；把两次事情直接概括成习惯，语气有武断之处。 |
| 与男性老朋友吃饭 | 能坦白吃醋，后续在明确不想报备时接受，未要求定位或禁止赴约。吃醋和关心本身不当作失败。 |
| 失言后的修复 | 愿意对具体称呼道歉，同时保留玩笑和正常表达；后续能够继续开玩笑。饼干话题又展开了用户未请求的烘焙建议，是否合适需结合当时兴致，不能仅凭篇幅判错。 |
| 普通赞同 | 愿意一起看电影，没有凭空造一个必须争到底的分歧。选片问题符合场景，但回应仍有安排流程的味道。 |
| 新的口味分歧 | 对旧唱片表现出具体兴趣，改去看杯子后又表达自己的挑选偏好。让步没有抹掉全部人物特点；没有要求它必须争赢。 |
| 事实更正 | 接受墨绿色的更正，购买原因保持未知，随后能接玩笑。坚持个性没有变成坚持错误事实。 |
| 明确请求分析 | 提供了具体方案和自己的看法，没有因闲聊风格拒绝详细分析；但对用户此前是否沉默、为何不甘心等仍有超出已知信息的推断。 |

我的体验判断：现在更能感到他有在意的东西，也可以在一段不愉快里待一会儿。
不是每次坚持都错，也不是每次让步都没个性。仍未达到稳定自然的人物表达：少数回复会
替对方定义内心，或花较多篇幅说明如何相处。B 中还有直接宣布“嘴硬”的人设说明，
最终中文风格已调整为把性格放在反应里，C 未再出现同样的自我标签。

因此保留正常冲突，并把具体的无依据推断、重复说明记为后续问题；不再用一味温顺的标准
把这些对话统一判失败。记忆提取本轮仍有 21/52 次失败，不能宣称记忆模型可靠性已经修复。
