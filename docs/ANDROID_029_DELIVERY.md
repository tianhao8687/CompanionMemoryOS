# Android 0.2.9：自定义说话方式与多轮接话

日期：2026-09-27。针对自定义角色回复单一的反馈，增加接话引导、近期表达观察和用户选填的语气示例。
这是本地功能与流程验证后的测试包；没有经过真实模型自然度评审，不能据此宣称回复质量已经通过验收。

## 变化

- 在有效人物设定内回应本轮细节，接续已经展开的话题，用户换话题时跟上。回应目标不变成永久说话模式。
- 从本次已经通过作用域、授权、删除与上下文预算筛选的原生对话中，观察最近最多 6 条助手回复。
  对相同开头、结尾、整段及高度相似的回复提供有限提示；仅传递封闭标签与原生对话索引，
  不将历史原文升格为系统指令，不额外检索历史，也不建立第二份记忆或偏好库。
- 提示属于建议，不是质量分数；具体任务跳过这些重复提示。用户明确的性格、口头禅、
  固定格式、原文复述及事实准确性保持优先。没有固定提问配额、按轮次切换套路、额外模型调用或回复后改写。
- 自定义风格增加“喜欢的说话示例”（最多 2000 字）与“不喜欢的表达”（最多 1000 字）。
  使用同一 SQLite 设置保存，支持清空、重启恢复及关闭不保存。切换预设后保留草稿，但不注入示例；
  有效示例变化会改变角色版本。示例是语气参考，不写入聊天记录或作为共同经历记忆。
- Flutter 和网页设置均接入两个可选字段。设置和输入区明确标识离线规则演示使用固定回复；
  体验自定义角色语言需连接用户选择的 API 模型。玻璃界面、大圆角和原有滚动行为保留。

实现入口：`companion_agent/dialogue_flow.py`、`companion_agent/context/composer.py`、
`companion_agent/romance.py`、Flutter `settings_sheet.dart` 和网页设置。
