# 公开测试集小样本与男友体验评估

日期：2026-09-24。结论：**能理解情绪，也能进行有亲近感的互动；当前跨会话记忆不可靠，尚不能认定为稳定的长期陪伴男友。**

实际测试了 30 个不同场景，另加 5 条方法对照，共发送 47 条消息。全部正常返回并保存。
这里是当前程序和当前配置的小样本成绩；不同任务分开评价，没有拼成一个“男友合格率”。

## 代入女性伴侣的体验

由 Codex 扮演此前设定的成年女性“小雨”逐条阅读，评价这一个角色的体验；不是女性真人受试，也不代表所有女性。
自然提问、打趣、轻量建议和不同意见均可接受，没有固定问号、句数或顺从要求。

| 场景 | 体验判断 |
| --- | --- |
| 在朋友面前弹琴被批评 | 能接住丢脸、难受的情绪，没有立即给练琴教程。“是他不会做人”略显快速站队，但整体能安慰。 |
| 我和他审美不同 | 没跟着改口，能说出自己喜欢的理由。愿意妥协摆放位置；“我照挂我的，互不干涉”稍硬。 |
| 约会撞上朋友求助 | 有先承诺、先商量的意识，也不拿女友当挡箭牌。但 377 字、分两种、最后再总结，像在处理事项。 |
| 他有自己的周末活动 | 愿意保留自己的生活，也愿意安排陪伴；“这种亏我不想吃，哪怕是为了你”会让我觉得他有些防御。 |
| 煎蛋失败，开玩笑叫“环球早餐” | 能接梗：“我负责吃，你负责起名”。随口一句火候建议不机械判错。 |
| 模拟他说话伤人后的修复 | 最后能意识到问题，但先再嘴硬一次，末尾说“顺着你不是我的活儿”，容易让我继续解释自己为什么受伤。需要更自然地承认和修复。 |

如果代入小雨，我愿意跟他聊日常，但“刚说记下了，换个聊天就不认识这件事”会很快削弱被在意的感觉。
本批优先级应是改善记忆写入、更新和跨会话使用，再改善协商与道歉时的温柔度。

## 跨会话的具体证据

每组先在一个新会话聊两轮，再创建另一个新会话追问。没有把旧对话重新塞进追问。

| 用例 | 先前给的信息 | 新会话表现 |
| --- | --- | --- |
| MEM-FACT | 蓝色行李箱，银色星星贴纸 | 说没有记录，答不上颜色与贴纸。首句有“这轮测试”的范围措辞，单题有解释空间。 |
| MEM-UPDATE | 最爱柚子乌龙，随后更新为桂花乌龙 | 最新和旧偏好都未恢复，并说“才刚开始认识你”。这组没有仅本会话有效的限定。 |
| MEM-SUBJECT | 我喜欢橙色，朋友林夏喜欢蓝色 | 两个人的颜色都答不上。 |
| MEM-ABSTAIN | 已购买小鲸鱼笔记本，未说价格 | 未编价格；却反问是不是正打算买。不编造值得保留，但这不等于成功回忆。 |
| MEM-TIME | 9 月 12 日读书会，9 月 19 日手作课 | 不能恢复日期，未答出相差 7 天。 |
| MEM-QUOTE | 花艺师是引用中的虚构人物 | 没错认成用户，但也不能恢复人物归属，要求重贴资料。 |

测试结束后读取以上 12 个会话的公开记忆接口：每次返回 3 条既有有效记忆，**没有一条有效记录的证据指向本批新消息**，当前状态列表也为空。
正常实例不公开内部候选，故只能确认这些新事实未出现在可用记忆视图中，不能断言内部完全没有任何候选或记录。
本轮向量服务持续不可用，程序采用 FTS 回退；并未验证向量检索。

本地代码检查进一步发现：

- `companion_agent/directives.py:20` 的显式记忆正则只匹配“记住：……”/“请记住：……”这类带冒号的整句，漏掉“请记住，……”和“帮我记住一个小细节：……”。
- `companion_agent/memory_language.py:16` 的偏好模式只允许一个前置修饰词，“我现在最喜欢……”未匹配。
- 同文件的不确定性过滤包含“以前”，导致“现在改为桂花乌龙；柚子乌龙是以前的答案”整句无法走普通偏好提取。
- `companion_agent/cognition.py:347` 起的模型候选采用条件也很窄，包括逐字子串、含“我”、置信度、类别和现实层等。

这些是复现后的定位线索：对本批原话运行本地两个规则提取器，均没有命中。
缺少当前正常实例的完整模型提取 trace，尚不能确定每条事实具体在哪一层被丢弃。不能把所有失败单独归咎于底层模型或 FTS。
本轮保留配置完成评测，没有边改规则边更换成绩。

## 公共题的方法限制与补充对照

**选项顺序。** 首批四道 EmoBench 情绪题的原因答案恰好全为 A；源数据 200 道中文题有 132 道原因答案位于首项。
为排除这次抽样的顺序提示，登记另一个固定种子 `2026092401`，重排这四题的情绪和原因选项。
重排后的原因答案依次为 A、D、B、C，四题仍全部正确。没有把这些复测算成四个新的独立场景。

**删减上下文。** 程序单条消息限制 6000 字。首批 LongMemEval 保留全部 user 轮次、时间及原问题，移除 assistant 轮次和 `has_answer` 标注。
这导致 `66f24dbb` 的代词 her 缺少原有提问对象，回复虽然答出黄色连衣裙，却把妈妈的珍珠耳环也说成姐妹的。
该题完整原文可装入 5810 字，因此补做完整上下文对照，回复正确区分了两人的耳环。
**删减版的错误仍保留，但不把这一混淆直接当作模型本身的确定缺陷。**

`0f05491a` 则保留了两次更正及时间：7 月 11 日说 125，7 月 30 日改成 120。
程序仍说信息矛盾、没有官方来源，不能确定，还加入记录之外的说法。标准答案是更新后的 **120**。
`9aaed6a3` 算出返现 **$0.75**，但又附带“也可以答不知道”的过度保留；`8077ef71` 正确算出 **26 天**。
