# 公开测评之后的记忆修复

2026-09-24。修复目标来自 [原测评](PUBLIC_BENCHMARK_REVIEW.md)：自然表达没有形成可用记忆、偏好更新失败、跨会话问答缺少证据，以及男友互动中商量和修复显得生硬。

## 改动

- 支持“请记住，…”“帮我记一下…”等普通说法，保留用户原话、来源和关系作用域。明确笔记可跨会话使用。
- 按分句处理当前偏好和旧值。“现在改为……；以前是……”不会再因“以前”让整句话失效。明确旧值可以定位同类偏好的更新，其他类别保持独立。
- 避免本地提取和模型提取为同一个偏好建立两条活跃记录，防止旧副本绕过更新。
- 模型提取明确要求置信度、逐字依据、主体和时间。提取使用独立的非思考请求和足够的输出额度；聊天模型原有的 thinking 设置不变。成功采用模型记忆也会产生实际保存回执。
- 在没有向量服务时，从检索问句中去除“那次”“是什么”“隔了几天”等提问成分，减少这些字的组合压低真正主题词匹配的情况。时间筛选和来源规则继续生效。
- 明确的单一过去日期或“昨天”按用户时区确定事件日期，保留原始发言时间和“日期”精度。多日期笔记和未来计划不会被粗暴归到第一个日期。
- 有明确分享框架的引用资料保存为“分享过的原文”，携带引用与虚构标记，不把引文中的“我”变成用户身份。
- 遗忘请求本身以及依赖已遗忘来源的后续回复不能从原始聊天检索回流。沿用原有记录、证据和反馈机制。
- 商量安排时允许直接表达自己的想法；道歉修复先回应具体感受。没有增加固定问句数量、永远不提建议等限制。
- 测试工具遇到 Windows 短暂文件占用时，只重试本地计数文件的原子写入，不重试模型调用或重置额度。
