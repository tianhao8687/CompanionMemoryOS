## 用户体验对抗结论

本轮不是只验证数据库 CRUD，而是集中覆盖了陪伴对话中最容易破坏代入感的运行时路径：

- 用户明确说“先听我说”时，不为个性化强行检索旧事，也不要求用户确认一张记忆卡。
- 用户问“还记得吗”时，首拍在证据就绪前不能声称记得，也不能因索引未完成说“你没讲过”。
- 用户说“不是那个”或“别再提”时，只有最近实际发送证据唯一才自动修复；多个目标时保守返回待定位。
- 用户换话题或发来新消息后，旧计划的未发送拍被取消，迟到检索不能重新插回对话。
- 用户报告事项已经结束时，只关闭当前话题唯一匹配的 OpenLoop，避免把另一件相似小事误判为完成。
- 同一 resolution key 的重试直接复用已保存结果；revision、策略版本和新用户回合共同阻止陈旧写回。
- 引用、转发或角色扮演 SpeechSpan 中的控制语不能操作真实用户的回复计划。
- 单消息渠道仍合并回复；多拍渠道按证据就绪释放，不加入固定等待秒数或通知轰炸。

## 当前可以成立的结论

- Conversation Ledger、原始 FTS/可选向量下钻、结构化记忆、事件、状态、引用反馈、OpenLoop 与 ResponsePlan 已形成可运行的原型闭环。
- 未被抽取成长期记忆的小事，只要已授权进入原始回合，仍有词法、多 key 和调用方提供的同空间向量召回路径。
- 当前话语优先、自然引用、明确回忆、必要消歧和抑制已由结构化 Memory Use Plan 表达，不需要每次打断用户确认。
- 0.6 的 staged plan 能把“接住当前话语”与“等待历史证据”分开，同时不假装已经回忆成功。
- 本轮所有用户行为参数仍受配置、策略清单与 AST 门禁约束；默认 Policy Bundle 明确不可生产。

## 仍然阻断生产声明的项目

### BLOCKED

1. **100M token 尚未实测。** 本轮没有目标设备持续写入、索引积压、断电/磁盘满、embedding 迁移、尾延迟和成本数据。
2. **“彻底忘记”尚未闭环。** 当前 `purge` 只覆盖当前主库及同步索引，未完成 WAL/free pages、旧备份、provider、日志和恢复后 tombstone 法证验证。
3. **静态加密与密钥擦除未实现。** Conversation Ledger 仍为 SQLite 明文，不适合真实高敏亲密数据生产部署。

### CONDITIONAL

- 确定性中文短语解释器不是完整 NLU；反话、方言、复杂否定和句内多次改口需要真实数据评测。
- 内核不含聊天模型、后台 worker、outbox、最终 transport、推送或日历提醒，不能把计划创建说成消息已经发送或提醒已经设置。
- 原始回合向量由宿主生成；当前本地余弦排序是线性扫描，不是 100M 规模 ANN 证明。
- `episode_id` 仍由宿主提供，尚无可撤销 mention 聚类及 merge/split 联合评测。
- 151 个用例以确定性合成场景为主，不能替代长期真实中文用户研究、方言切片和端到端主观代入感评测。
- 本轮没有真实测量 staged 首拍的 P50/P95、token 节省、用户打断率或重问率。

## 发布裁决

可以提交并上传为 **CompanionMemoryOS 0.6 关系记忆原型**，用于继续开发、集成测试和 shadow 重放；不能宣传为生产就绪、已经支持一亿 token、能够彻底忘记，或已经证明能提升真实用户的情感陪伴体验。
