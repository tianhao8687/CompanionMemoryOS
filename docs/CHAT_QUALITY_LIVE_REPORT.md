## 已定位的问题

1. **并列偏好漏识别。** 对本批实际输入运行当前本地解析器：“我不喜欢被分析，也不想一直被追问……”只产生心理分析偏好；“以后别一直追问我，也不要主动给建议”只产生追问偏好。普通记忆接口也只返回这两个测试来源的有效偏好，没有建议偏好。不能把模型回复“记住了”当成持久化成功。
2. **旧对话内容仍能带入当前开心。** 奖金回复参与了开心，但同时重新提起旧工作烦恼。本实例未启用完整请求诊断，所以不能仅凭这次输出断言是某个上下文片段或生成阶段单独导致；需要在修复时复现最终模型请求。
3. **偏好存在不等于生成遵守。** “减少追问”已有有效记录，新会话仍会主动发问。普通接口没有暴露最终偏好投影，尚不能进一步区分投影失效与模型看到约束后仍未遵守。

最后一轮还有一个细节偏移：输入只说朋友不喜欢下雨，模型改述成朋友“不喜欢湿鞋”。这不是用户提供的事实。
