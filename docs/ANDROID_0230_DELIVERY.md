## 功能与开启

「连接 → 手机能力 → 聊天中的手机陪伴 → 屏幕柔和一点」。旧版已开启这一项时，
关闭再开启以允许新增传感器读取。升级不会自行放开新权限。

原样复用固定 droid-mcp v0.11.0 的六个传感器源码文件，保留许可证和来源校验。
公开环境光和接近两个工具；沿用 Python ToolHub、JNI、原生桥与现有操作记录。
接近距离在心隅桥接层按设备量程校正，未修改上游源码。

模型根据当前聊天决定是否需要屏幕陪伴；实际执行前短时读取光照和接近状态。
仅在前台解锁、手动亮度、低光稳定且未疑似遮挡时小幅调暗；亮度较低、自动亮度开启、
环境偏亮、疑似遮挡、读数缺失/过期或变化过快时保持现状。
恢复、30 分钟冷却、拒绝停用和手动操作优先继续生效，兼容旧版待恢复的自动亮度模式。
策略阈值、数据记录及运行范围见 `docs/PHONE_COMPANIONSHIP.md`。
