# 心隅内置手机能力

Android 9/API 28 及以上可在「连接的应用 → 手机能力」连接。本轮接入
droid-mcp v0.11.0 的 26 项工具：手机状态、媒体音量与亮度、轻振、系统闹钟与计时、
应用查询与启动、勿扰、无障碍界面读取与操作。其余心隅功能仍保持 minSdk 24。

已补齐依赖并交付本地 [Android 0.2.27 测试 APK](ANDROID_0227_DELIVERY.md)，包含网易云此前更新。

0.2.28 新增长按控件（`long_click_node`）和滑动手势（`gesture`），仍直接复用固定版本的
droid-mcp 实现。可用于打开应用的长按菜单，以及滑动列表或应用自定义控件。
在「连接 → 手机能力 → 界面操作」开启后使用；旧连接升级时，新工具保持关闭。
滑动手势需要 Android 11/API 30 以上，以系统 Insets 排除状态栏、导航栏和边缘系统手势区域；
Android 9–10 保留长按及原有按控件滚动（共 25 项工具）。
长按根据当前界面的文字或控件 ID 定位；滑动仅接受目标窗口内的 2–16 个坐标点，
持续时间为 10–3000 毫秒。结果区分手势完成与业务结果，执行后需重新
读取界面核对。确认卡片会显示长按目标或滑动起止位置。

## 复用与项目适配

- 上游固定到 `38723823a05852d3b2a655f48d817fc4bd3b406c`。`android/droid_mcp`
  保存 62 个未经修改的上游文件、Apache-2.0 许可证和 SHA-256 清单。
  用 `tool/vendor_droid_mcp.py` 从固定版本 Git blob 更新，避免 Windows 换行影响校验。
- 直接复用 ToolRegistry、InProcessTransport、JSON Schema 生成及 Android 工具实现；
  本地 Gradle 配置沿用项目工具链。未引入 HTTP 服务、JitPack 动态版本或外部后台进程。
- `android/phone_bridge` 是心隅的独立适配模块，负责 SDK 版本门槛、结果核对、权限预检、
  输出限额和界面目标检查，可单独编译及运行 Robolectric 测试，不依赖 Python ARM64 wheel。
- Python 经 Chaquopy 调用 PhoneBridge，`NativeClients` 同时分发 droid 和 netease。
  原有桌面 ADB 模板 `/api/automation/phone-template` 保留；新模板为 `/api/automation/droid-template`。
- 工具配置、确认、去重、执行记录继续使用 ToolHub 和原有 SQLite，没有另建记忆数据库。
  Flutter 只请求打开固定的权限设置页，不提供绕过 ToolHub 的执行通道。
- 许可证随 Flutter assets 打包并注册到开源许可页；APK 检查覆盖 PhoneBridge JNI 签名、
  Python 适配模块及许可证资产，R8 保留通过反射调用的 PhoneBridge。

## 操作规则

连接默认关闭；连接后基础操作默认逐次确认，界面操作默认关闭。
各组能力可独立设置「操作前确认／按要求直接执行／关闭」，与网易云配置互不覆盖。
0.2.29 增加独立的 [聊天中的手机陪伴](PHONE_COMPANIONSHIP.md)：一次性选择可主动调整的
媒体音量、屏幕与勿扰后，按当前聊天判断时机，支持冷却、拒绝及恢复；通用界面操作仍按明确要求执行。
系统特殊权限由用户在设备设置中授予或撤销，回到连接页面会刷新状态。
确认卡片展示中文操作说明，例如计时长度、闹钟时间与重复日、目标媒体音量、勿扰模式；
完整参数仍可展开核对。界面读取和控制从聊天工具循环执行，不新增第二个聊天入口。

仅开放媒体音量，亮度下限为 10；亮度修改会切换为手动模式。系统勿扰效果需要读回核对，
Android 15+ 系统可能合并其他勿扰规则。应用启动只有在无障碍服务观察到目标应用前台后
才报告成功，否则保持待核对。闹钟和计时器以系统时钟实际接收为准，不自动重试。

界面读取及操作要求 `expected_package`，前台应用不匹配时停止。节点操作进一步限定包名；
读取期间应用切换时丢弃结果。心隅自身、系统设置及 System UI 不通过该入口操作。
上游对密码标记节点作遮罩；普通界面文字仍会按用户授权进入当前配置的模型和操作记录。
输出截断保留合法 JSON 并标注 truncated。一次任务内，写操作后不会复用写操作之前的屏幕结果。
点击、输入、滚动等操作需先读取同一目标应用；同一步重试复用执行记录，重新读取后才可
以相同参数执行下一步。这样既能连续滚动、点击同名控件，也不会因请求重试重复执行。

截图/视觉模型输入、Root/Shizuku、短信/联系人/日历专用接口、定时恢复设置和后台常驻
不在本次开放范围。没有专用支付流程；通用界面操作不等于系统级支付拦截，发送、删除、
支付等操作仍须对应的明确授权。无障碍控件不完整或系统限制后台启动时返回失败或待核对。
「操作前确认」若使前台切回心隅，将停止原目标的界面操作；连续操作需用户明确开启直接执行。

当前源码在此基础上增加「触感陪伴」，尚未打包到 APK。直接复用上游 `vibrate_pattern`
与 `cancel_vibration`：短拍两下共 0.36 秒，三次间隔短震共 4.64 秒，均不循环。
例如“用短震拍我两下”或“用慢一点的震动节奏陪我缓一会儿”，也可以说“停止震动”。
新连接默认操作前确认；旧连接新出现的工具保持关闭，可在触感陪伴分组按意愿开启。
开始时要求心隅前台、屏幕解锁且未通话，停止指令不受前台限制。只开放这两个完整节奏，
不接受任意长振动或循环；确认卡片显示实际时长。SDK 成功仅证明系统接收指令，
不能证明用户感觉到震动或情绪有所改善。该能力不纳入主动音量、亮度和勿扰的授权。
当前源码 Android 11+ 为 30 个工具，Android 9/10 为 29 个。

「随回复表达触感」可在手机能力面板单独开启，默认关闭。开启后模型结合对话，为自己
情感浓烈的回复选择一次短拍；回复成功完成且选定句子确实出现后，才通过原有 droid-mcp
工具下发 0.36 秒的两下短拍。每条最多一次、全局至少间隔 20 秒，重试/历史加载不重放，
手机前台/解锁/未通话限制不变。说“别震了”会保存关闭设置；引用和假设不作为关闭指令。
此开关独立于音量、亮度、勿扰联动，不能扩大界面操作权限。
实现与当前测试范围见 [触感陪伴记录](HAPTIC_COMPANIONSHIP_TESTING.md)。

2026-10-19 源码新增「陪我看消息」：独立开启并逐次确认后，读取微信或 QQ 当前通知
预览，在原对话里帮助理解、起草回复。默认最新 1 条，最多 3 条；可按通知标题筛选。
该功能通过现有 droid-mcp 注册及执行通道接入，有独立的通知权限入口，不沿用网易云
的授权，不后台收集、不发送消息。当前源码 Android 11+ 共 31 个工具，Android 9/10 为
30 个。使用、复用范围和测试记录见 [陪我看消息](CHAT_NOTIFICATION_COMPANIONSHIP.md)。
