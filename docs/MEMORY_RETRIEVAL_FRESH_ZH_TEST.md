# 全新中文题的冻结测试

日期：2026-09-29。测试对象为上一轮优化后的代码，本轮没有根据新题修改生产代码。

## 结论

使用本轮才启用的 12 位人物、860 条原始聊天消息和 78 道中文题，分别运行
FTS、hash 和本地 BGE 三种配置，共 234 次检索，全部正常执行，无重试。

| 配置 | 证据召回 Recall@6 | 任一证据 Hit@6 | 标注证据找齐 | 首条命中 P@1 | P50 | P95 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| FTS | 76.28% | 79.49% | 57/78，73.08% | 44/78，56.41% | 16.49 ms | 22.40 ms |
| FTS + hash | 72.65% | 75.64% | 54/78，69.23% | 46/78，58.97% | 18.68 ms | 24.21 ms |
| FTS + BGE 中文向量 | 85.90% | 85.90% | 67/78，85.90% | 43/78，55.13% | 30.28 ms | 46.90 ms |

判断：这批小规模中文历史的检索延迟较低，但召回还不够稳，首位排序尤其有改进空间。
BGE 找齐标注证据的题数最多，仍有 11/78 道没有命中指定证据；这些不等于 11 道最终回答错误。
旧 21 题的 100% 不能当作未见问题的水平。两批题目与评分标签不同，也不能据此声称代码退化。

**这里没有测最终回答正确率。** 未执行模型提取、聊天 HTTP 请求、最终证据使用决策或回答生成。
P@1 只是第一条原话来源是否命中标签，不能称为回答准确率；没有远程模型调用。

## 为什么算新题

数据来自 [MemoryBank 官方仓库的中文评测数据](https://github.com/zhongwanjun/MemoryBank-SiliconFriend/tree/cf61c4196e4cfdb0f2b7a0316249fa40312dc3a9/eval_data/cn)。
固定上游提交为 `cf61c4196e4cfdb0f2b7a0316249fa40312dc3a9`。

- 排除旧 21 题使用的 3 位人物，不改写旧题，不沿用其历史。
- 使用剩余全部 12 位人物：孙悦、周立、刘琳、张志强、宫晓燕、郝明、姚国栋、曹志强、陈阳、郑思雨、陆琳、焦彦。
- 原有 79 道未用人物题，与旧 21 题及 PerLTQA 585 题进行 NFKC、大小写与标点归一化后的精确去重。
- 剔除 1 道与旧题同文的 `周立:1`，剩余 78 道；题型相近、措辞相似不算精确重复。
- 先阅读完整历史、固定证据标签和代码指纹，再执行一次评测；没有看完分数后改标签、换题或调阈值。

“新”仅指未用于此前开发和测试的人物、历史和问题，仍来自同一公开数据集，
不是刚创作的数据，也不能保证编码模型预训练时从未见过。上游记录是合成对话，不代表真实用户分布。

## 评分和边界

证据标签由 Codex 在检索前阅读完整历史后整理，不是官方逐消息金标，也没有独立人工复核。
每题有一个或多个必需证据组；组内可列等价来源，命中任一条即覆盖该组。
Recall@6 是逐题的必需组覆盖率再取平均；“找齐”要求该题全部标注组被前 6 条覆盖。
因此多证据题只找到一部分时会获得部分召回分，但不算找齐。

严格来源 P@6 分别为 FTS 14.53%、hash 13.68%、BGE 15.81%，分母固定为 6。
标签主要给出足够回答的原话，未穷举所有主题相关的消息；这个数不代表剩余消息全部无用。
同样，找齐标注来源也不保证模型能够正确归纳或处理否定、日期与事实真假。

每位人物、每种配置均使用独立的新 SQLite，保留日期、每日会话、角色和问答关联。
仅原始 query/response 入库，不导入人物画像、官方记忆摘要、测试问题或预期答案。
新会话查询，原话上限 6 条、2500 token、12000 字符；各模式同一配置，无超预算截断记录。
历史日期按 UTC 导入；查询时间为该人物最后一条历史之后一天；不测试跨时区推断。

860 条是全部人物的合计，每个被查询的库只有 36 至 96 条原话，不是单库 860 条压测。
延迟是 Windows 11、Python 3.12.14、单客户端下的本机查询编码、检索和上下文渲染时间。
BGE 使用已有的 `BAAI/bge-small-zh-v1.5` CPU 缓存、4 个线程和 512 token 编码上限。
计时不含加载模型、历史入库、提取、HTTP 和生成；不能用 46.90 ms 代表完整聊天耗时或大库性能。
没有使用日常对话数据库，没有开启真实渠道、设备或外部动作。

BGE 的全部 11 道严格来源未命中题保留在逐题结果中：

- 日期、首次对话和跨原话信息：`孙悦:3`、`刘琳:2`、`张志强:1`、`宫晓燕:0`、`姚国栋:4`、`陈阳:2`、`陆琳:1`。
  有些只找到了当天的开场情绪，没有找到后文具体原因；有些召回其他日期的泛泛聊天。
  当前 `temporal.py` 的显式中文日期需要年份，没有覆盖本批常见的省略年份的月日问法。
  首次对话与多条主题归纳还需要正确定位会话和补全上下文，单靠语义相似不足。
- 助手旧回复：`郝明:3`、`郝明:5`、`姚国栋:2`。已检出用户当初的请求，却没有返回具体书单、做法或节目名所在的助手回答。
  `recall_completion.py` 的历史回复识别没有覆盖“和我”修饰语和“教”动作，这是与失败表达直接对应的覆盖缺口。
- 严格标签局限：`孙悦:4` 没有命中预先标注的明确喜好原话，但返回了多条正面健身经历。
  这些文本可能足以支持合理回答，不能据此判定最终答案必错。本轮保持冻结标签，没有补标来抬高分数。

宽泛分享类问题也有解释空间，例如 `刘琳:0` 的标签同时覆盖已读与计划/推荐书籍，
不能把它们全当成已读经历。此类人工标签误差及未穷举等价来源都限制了数字的外推性。

下一轮值得优先验证的方向是无年份中文日期、旧回复指代，以及同一会话内的相邻原话补全。
这些是后续开发建议，不是本轮已完成的优化。以上 78 题用过后应算回归集，再优化时另留新题验收。
