## 边界与后续验收

持久偏好的识别仍是有界解析，并非通用语义理解。未识别表达保留为证据，不能宣称所有措辞均可自动沉淀。
真实模型看到正确约束后是否仍过度分析、持续追问或书面化，需要在获批模型配置下检查实际回复。
已有 `full / no_examples / no_history / no_old_conditions` 对照入口；后两种尚未进行本轮独立场景验收。
没有用固定句数、问号数量、被测模型自评或离线非空回复替代自然度评估。

虚拟时钟只覆盖事件到期选择与静默时段；认证、网络超时、安全冷却保持真实时间。
它不代表真实经过数天，也不覆盖所有记忆过期、相对日期与双时间线路径。
真实微信、外部通知、设备控制等未启用。平台和真实模型未覆盖项均保留独立状态。

所有链接到 `.agent-tests` 的原始证据仅在本地保留，不提交 Git；保留期后这些链接可能失效。
运行 `python -m companion_agent.testing cleanup --run-dir .agent-tests/<run_id>` 可清理对应已关闭批次。
