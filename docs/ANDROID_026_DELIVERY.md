# Android 0.2.6：圆润选项界面

日期：2026-09-26。按用户要求，统一选项界面的圆角、胶囊形与玻璃质感。
本轮只调整 Flutter 界面；聊天、角色、记忆和存储规则不变。没有新增重发或玻璃强度选项。
未上传 GitHub、未运行 GitHub Actions。

## 界面变化

- 弹窗采用 32 圆角、内容卡片 28 圆角、输入框 24 圆角；按钮、标签、选中项为胶囊形，复选控件为圆形。
- 设置四个入口在窄屏上以两列排列，完整显示“连接与数据”；滚动区域本身也圆角裁切。
- 下拉列表使用统一的选择控件，外框、选中、鼠标经过及键盘焦点都有圆角，保留原选项和值。
- 长按菜单改为留有外边距的玻璃面板，四角圆润；手账类别与约定/纪念日切换使用独立胶囊标签。
- 角色主页、收藏、搜索、来源弹窗、日期/时间选择器和提示条同步统一。
