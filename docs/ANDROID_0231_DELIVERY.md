## 本版内容

- 免费本地语音输入：在聊天输入栏点「语音输入」打开「说给我听」，首次主动下载约 190 MiB
  资源。开源 sherpa-onnx / Zipformer 在手机上识别中英文，无需额外语音账号或 Key。
  打开面板预加载、同面板复用、加载期间暂存开头音频；转写可编辑，确认后仍手动发送。
- 悬浮陪聊：聊天右上角开启，收起为边缘小点，支持拖动、贴边、展开和原对话同步。
  「点开时看当前屏幕」需要单独开启及无障碍权限，读取本次可见页面供当前聊天模型理解。
- droid-mcp 手机能力及网易云连接；手机情绪联动、环境光/接近状态、1/3/5 分钟冷却、
  暂停、恢复与保留、强烈情感回复触感。功能范围继续遵守用户选择与 Android 系统权限。

语音权重未内置到 APK，录音不上传、不保存。聊天仍使用用户自行选择的回复方式，
联网聊天模型与免费本地语音识别分别配置。「开口练习」「陪伴通话」未加入本版。

## 本轮发现并修复

sherpa-onnx Android 1.12.14 附带未使用的 `libonnxruntime4j_jni.so`，其 LOAD 段仍为 4 KB。
心隅通过 Dart FFI 调用 C API，原生依赖表也没有引用这个 Java 适配库；现在仅排除该库，
保留固定版本的 C API、ONNX runtime 和实际识别路径，不升级已验收的语音模型或原生库。
构建检查新增 ELF 检验，不能仅用 ZIP 对齐结果宣称原生库兼容。
初始包与失败证据保留，发布的是修正后重新构建及测试的最终包。

测试探针的旧工具目录数量断言由 30 更新到当前 31；探针单独安装，不包含在交付 APK 内。
