# Android 0.2.7：发送前提醒与统一问题弹窗

日期：2026-09-26。只在本地修改、测试和打包，没有上传 GitHub 或启动 Actions。

## 问题与修改

原发送按钮在聊天授权或识图条件不满足时直接打开设置，缺少原因说明；
控制器的 ready 检查也没有检查联网模型的 model_ready/Key 状态。

- 联网模型缺 Key、未确认聊天选项、本机引擎未连接、图片识别未就绪分别说明原因。
- “稍后再说”关闭提醒；只有主动点击“去设置”才进入“连接与数据”，不自动发送消息。
- 未通过检查时，不消费输入、引用和待发送图片，不进入连续消息合并，不发模型请求。
- 离线规则回复仍无需 Key；它需要用户确认本机保存和所选回复方式处理消息，不是本地大模型。
- 启动、聊天、设置及备份操作、图片导入、角色资料、搜索、收藏、手账、日期提醒、来源读取和
  复制等已捕获的用户操作失败，统一使用圆润玻璃弹窗。保留后端提供的明确原因；常见连接、
  超时、文件、数据格式及系统异常转换成说明，不明原因不伪称为 API 或网络错误。
- 同时出现问题时更新同一个弹窗，避免叠出多层提示。关闭弹窗不清空编辑表单或草稿。
- 复用原有错误显示及失败请求处理；没有新增重发或重新生成按钮。

后续功能可调用 `CompanionController.reportFailure` 或 `reportProblem` 接入同一提示入口。
本次不修改后端记忆、角色优先级、授权规则或模型调用路径。
