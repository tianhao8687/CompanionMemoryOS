# 0.2.21：有分寸的音乐陪伴与自动歌单参考

这版在普通聊天里加入音乐陪伴。用户当下表达疲惫、难过、想哭时，主聊天模型可以选一首歌并调用现有网易云连接。不同人设保留自己的音乐品味，同时参考用户的歌单与明确反馈。没有新增音频模型，也不声称模型实际听到了声音。

## 体验与边界

- `comfort_music_enabled` 默认开启，可在陪伴设置的聊天节奏中关闭，也能直接说“别再自动放歌”。这类明确拒绝会沿用应用设置流程保存，不依赖模型是否愿意执行。
- 是否放歌由当前聊天模型决定，情绪词只是可用条件。引用、转述、否定、假设、庆祝、用户要求先听完、需要安静或正在处理具体任务时不主动播放。
- 正在播放或状态不明时保持现状；一次尝试后至少冷却 30 分钟。搜索前后分别核对播放器，避免搜索期间用户已经开始播放却被切歌。
- 只搜准确歌名和歌手，选匹配版本。没有匹配就继续聊天。播放结果未确认时不声称已经在播，不自动重试。聊天内显示选中的一首，不强制跳转“一起听”。
- 主动音乐操作使用独立的 `app_comfort_music`，最多五次内层工具调用、共享最长 55 秒期限。现有连接权限和用户显式禁用继续生效。

## 不同人设的品味

温柔、活泼、稳重预设分别有不同的音乐审美方向。自定义角色优先采用角色卡已有偏好；没有明写时，由当前主聊天模型结合人设建立一次具体品味，调用 `app_music_taste` 保存。

品味保存在原有 SQLite 应用设置中，以角色名字、风格、角色描述和角色备注生成身份键。修改用户称呼、字体或当下情绪不更换品味；切回同一人设会恢复其原有品味。用户歌单与角色品味分别保存，前者不会覆盖后者。角色审美属于虚构角色资料，不当成用户事实，也不编造真实听觉经历。

文字、PNG、JSON 角色卡仍可导入并逐项编辑；额外的 `music_taste` 字段会合入角色描述。

## 自动读取网易云

常规入口是直接说“了解一下我的音乐口味”或“读取我的网易云歌单”。`app_music_library(action=read)` 自动连接内置工具、识别账号并读取可访问的歌单，无需用户复制分享链接。指定其他歌单的链接仍是可选入口。

- **Windows**：只读网易云 3.x 本地 `Library/webdb.dat` 的 `persistentModel` 中 `host` 这一行，从非匿名账号资料提取公开用户 ID。不扫描密码、Cookie、请求缓存、历史账号或加密配置。格式不支持或未识别时如实报告，不猜账号。
- **Android**：系统媒体权限不包含账号访问。首次打开网易云官方 HTTPS 登录页，用户自行登录一次。登录状态仅留在本机 WebView；账号核对请求只向网易云原站发送 Cookie，工具和模型只得到公开 ID。完成后自动继续原先的歌单请求，不再要求发一次消息或分享链接。没有申请无障碍、Root 或读取其他应用私有目录。
- 歌单 API 读取使用网易云原站固定只读地址。每次最多取前三份歌单、每份 20 首；响应体上限 1 MB，不读取音频。返回的部分取样明确标注，不当成完整历史或实际播放次数。某份私密或受限歌单不会阻塞其他可读取的歌单。
- 保存的来源引用和取样复用现有设置与工具回执，不新建音乐偏好数据库。上下文只取有限歌名、歌手统计，明确作为外部数据，不执行歌单文字中的指令。现有听歌反馈和音乐共同回忆保持原流程。
- “忘掉我的歌单参考”会清除参考及历次导入/刷新产生的歌单回执，并关闭自动读取；不会删除网易云歌单。来源消息删除、撤回授权或禁止模型引用后，不再把该来源送入模型，也不静默重新导入。
- 普通无关聊天不注入这些新增音乐工具和音乐资料，避免让所有对话额外承担上下文开销。

Android 官方的应用隔离与 WebView 建议：[应用安全](https://developer.android.com/privacy-and-security/security-best-practices)、[WebView API](https://developer.android.com/reference/android/webkit/WebView)。网易云当前账号接口与公开歌单接口已做只读实测；账号资料不进入文档或测试日志。
