# 心隅 0.2.20：直接点歌与自动唤起

进入“一起听”后，Windows 和 Android 都自动唤起网易云。每次页面进入只执行一次；
状态轮询、页面重建、从网易云返回心隅不会再次启动。启动期间离开页面会取消后续唤起。
返回聊天后重新进入正在进行的“一起听”，仍能再次打开播放器。

内置网易云的找歌、打开、读状态、播放控制和跳转默认按用户要求直接执行。
旧版普通逐次确认规则在首次升级时迁移；禁用状态、参数范围和其他应用权限保留。
用户之后主动选择的“逐次确认”或更小累计预算在重启后仍保留。
仅对内置 native 连接和当前引擎的固定网易云命令生效，自定义同名连接不自动放宽。

明确点歌且匹配后继续执行；只找歌、分享歌词不自动播放。不同歌曲/版本有实际歧义时仍需选择。
打开请求与实际播放继续分别记录；失败或不确定的外部动作不会自动重做。

## 上下文与继续执行

- 应用输入上限由 16,000 提高到 64,000 token，编排器与上下文组装器使用同一上限。
- 预留最多 8,192 token 给后续工具结果；预留量不是发送内容，不产生模型调用。
- 整轮累计默认预算由 30,000 提高到 240,000，避免扩大单次容量后仍被旧累计值提前截停。
  这与单次窗口不同，包含多次请求各自的输入/输出；已有非默认预算保持不变。
- MCP 同一结果的 JSON 文本和结构化副本只向模型发送一次。歌曲卡片的图片/链接留在 UI；
  模型仍收到全部候选 ID、歌名、歌手、专辑、时长及歌词匹配证据。
- 原始结果完整保存在 SQLite 中，不截断保存记录，也不把记忆当作工具授权。
- 确认后的续行按当前请求获取执行记录，播放器轮询不会把搜索结果挤出最近记录列表。
  已执行动作保持幂等，不在恢复回复时重新播放。
