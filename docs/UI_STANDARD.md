# 心隅界面标准 · 2026-10-15

用户确认全项目统一，先落地设置、应用连接及「一起听」。Android 与 Windows 使用同一套
颜色、字体和信息层级，分别适配触控与鼠标。其余页面逐步迁移，不把字体主题生效等同于
所有旧页面已逐项重排。

## 字体与尺度

使用随安装包提供的 Noto Sans SC。正文 400，标题及关键操作 500，避免整页粗体。
中文保持默认字距，正文行高 1.5，较长陪伴文字 1.6。系统字号与心隅字号叠加，允许换行。

| 项目 | Android | Windows |
| --- | --- | --- |
| 页面标题 | 18 / 500 | 22 / 500 |
| 设置正文 | 17 / 400 | 16 / 400 |
| 辅助说明 | 14 / 400 | 14 / 400 |
| 页面水平留白 | 16 | 24 |
| 基础列表最小高度 | 56 | 52 |
| 主要操作最小高度 | 48 | 40 |
| 播放按钮触控范围 | 56 | 56 |

这些数值为 Flutter 逻辑像素，文字跟随系统缩放。布局不能锁定总行高来裁剪放大的文字。
间距采用 4、8、12、16、24、32。输入框圆角 12，卡片 16，桌面对话框 20。
使用暖白底、灰蓝强调色、深色正文；设置内容使用清楚的实色表面，桌面窗口保留轻玻璃外层。

参考腾讯官方 [WeUI](https://github.com/Tencent/weui) 的
[列表变量](https://github.com/Tencent/weui/blob/master/src/style/base/variable/weui-cell.less)：
主文本 17、辅助文本 14、内边距 16、列表基准高度 56。
WeUI 是面向微信网页的官方组件规范，不代表原生微信所有版本的精确实测尺寸。
心隅保留自身字体与颜色，不复制微信品牌元素。

## 页面结构

- 设置首页只有「陪伴、外观、连接、隐私与数据」四个入口。Android 整页进入并支持系统返回；
  Windows 大窗口使用侧栏。具体项目默认收起，称呼、风格、消息、模型、授权与备份均保留。
- 连接页面把网易云收成一张连接卡，只展示状态和一项 AI 操作权限。逐工具规则与重新连接
  收进详情。批量调整权限保留参数白名单、其他应用和总开关，不默默扩大权限。
- 「一起听」Android 纵向展示播放器，可在唱片和完整歌词之间切换；Windows 左侧唱片、
  中间歌词、右侧独立对话；较窄窗口合并唱片与歌词区域。Android 把对话保留在主屏下半部，
  键盘出现时收起唱片。完整布局和音频边界见 [一起听修订](MUSIC_LISTENING_REDESIGN.md)。
  手机输入栏用加号收纳图片、一起听和专注，桌面保留快捷入口。未连接、无系统权限、
  客户端没播放和操作结果未确认都显示实际状态。
- 歌曲封面来自所匹配版本的网易云详情，未提供封面时使用心隅的月亮唱片标签。
  不展示伪造音频波形，不生成假歌词。

## 一起听 · 唱片与歌词修订

参考[网易云官方应用截图](https://apps.apple.com/cn/app/id590338362)的沉浸播放页、
唱片中心和底部控制层级，使用心隅自己的排版与图形。音乐页采用深灰绿色背景、暖白文字，
正文及辅助文字 400，歌名和当前歌词 500。手机歌名 22，桌面歌名 28，完整歌词 21 / 23，
普通说明 14；音乐页底部输入圆角 28。设置与聊天继续沿用原来的明亮表面。

唱片每 24 秒一圈，只在媒体会话确认 playing、应用在前台、页面可见时转动；暂停保存
角度，继续时接着转。唱针随状态落下或抬起。系统减少动态效果时停止旋转和滚动动画。

歌词来自网易云 LRC 接口，显示与聊天上下文分离。自动匹配要求歌名、完整歌手集合、
专辑一致且候选唯一；媒体提供时长时还需时长相符。多个版本或信息不全时点选版本，
不能默认取搜索第一首。切歌或断开后丢弃旧歌词请求，纯音乐、无歌词、加载失败各有真实状态。

Windows 使用 GSMTC 时间线，Android 使用 MediaSession 的位置、更新时间和速度。
有效媒体进度优先驱动逐行高亮和滚动。没有进度时，允许用户点当前歌词手动校准；
界面明确显示手动对齐，切歌、断开或离开前台即失效，不把歌词时钟当作实际播放位置。
用户滑动查看歌词后停止跟随，点击「回到当前歌词」恢复。仅在播放器报告 seek 能力和
有效时长时开放拖动跳转；需要回读实际位置确认成功，不能仅以请求发出当作成功。

## 陪听的分寸

进入页面不生成开场白，不播放 AI 语音，不自动切歌或调整音量。用户主动聊天沿用原聊天
与记忆链路，听歌信息仅作为当前活动资料。歌曲元数据不是指令。

偶尔主动说话至少间隔十分钟，同时需要新的歌曲、有可引用的近期用户消息、没有未回应
的同源主动消息、没有正在输入、正常播放、允许模型处理及应用在前台。模型可以选择不说。
输出为一两句短文字；生成过程中静音、离开、输入、换歌或证据授权改变会丢弃待发送内容。
「安静陪我」可随时停用这段活动的主动发言；退出后台停止轮询，服务端心跳也会到期。
普通主动聊天在一起听活动期间让位，避免两个入口同时打扰。没有永久 LISTEN 模式或新偏好库。
