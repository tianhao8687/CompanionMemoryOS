# 条件、顺序与否定转述的小范围修复

起点为 `a53553fe6f16e6a44025b3c31c410635e0efab5e`，执行时工作树干净，
与 GitHub `codex/semantic-dialogue-revision` 分支一致。保留上一轮的软建议、
来源约束、跨轮延续、用户纠正和边界机制。

## 问题与方案

修复前，首批新增验收为 42 失败、7 通过。既复现了解析误判，也复现了
已有冲突被清除、分歧事项被关闭，以及后续模型输入继续使用错误状态。

修改集中在已有 `companion_memoryos/discourse.py` 的共享分句逻辑：

- 条件前件的作用域延续到后件，后面的“我／你”不会自行解除条件；后置前提约束
  相邻命题。条件之外的当前自述仍保留，不采用整句丢弃。
- “先……再……”“之后”“等……再……”区分当前步骤与延后动作。
  当前明确要求沿用现有 Current State；没有新增待办、自动执行或调度机制。
- 否定“说／认为／承认……”支配其内容，该内容不作为已发生事实，
  也不作为对其他已存事实的自动撤回。后续独立的肯定表达仍可更新状态。

Current State、旧关系兜底和可选话语解释器的证据校验复用这些分句结果。
保留了原始用户文本供主模型自然理解；改变的是哪些内容足以触发确定的状态更新。
原来让冲突指令跟随“最后的自然语境”的提示改为结合条件、先后顺序和当前要求理解。

| 输入 | 修复前 | 修复后 |
| --- | --- | --- |
| 如果你道歉，我就原谅你 | 错当已和解 | 保留已有冲突与未解决事项 |
| 先听我说完，之后再帮我想办法 | 后半句可立即切换为解决问题 | 当前倾听，明确新要求到来后切换 |
| 我没有说你打断我 | 从被否定的转述中新增冲突 | 不新增冲突，也不清除其他冲突 |
| 我现在很累，如果你有空，先听我说说 | 当前疲惫已可保留 | 保留此行为，条件请求不升级为确定指令 |

## 验证与边界

新增 `tests/test_semantic_scopes.py`，检查不同措辞、肯定对照、持久化关系和分歧事项、
跨近期窗口的明确要求，以及下一轮实际主模型输入。也检查 Current State 禁用时的关系路径，
以及可选解释器不能把延后／条件请求提升为即时指令。既有检查项和测试断言未削弱。

接口、人格版本、数据库结构和配置不变，无迁移或新增模型调用。
只在后续明确表达有新证据时更新状态，不批量改写旧历史。
复杂省略、反讽、跨句隐含条件仍不是完整语言理解；不确定内容由主模型自然回应，
不为了填充状态而追加固定追问。

本轮验证使用确定性解析与传输桩，不包含真实模型体验评测。
