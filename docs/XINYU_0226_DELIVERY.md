# 心隅 0.2.26 · Windows 交付说明

2026-10-17。发布版本为 `0.2.26+29`，标签为 `xinyu-v0.2.26`，源码以 `main` 为准。
[下载 Release](https://github.com/tianhao8687/CompanionMemoryOS/releases/tag/xinyu-v0.2.26)。

## 这次更新

- Windows 点歌改用已登录网易云的本机后台控制通道，保留原队列。实际歌曲 ID、播放状态和
  推进中的进度核对成功后才报告播放成功；控制通道不可用时明确报错，不唤起窗口补救。
- 修复歌单“账号已识别，却读不到歌曲”的问题：替换失效的旧接口，只补取当前页缺失的歌曲资料，
  维持歌单顺序。部分取样不被当成完整听歌历史。
- 不同人设可保留各自的音乐品味，参考当前账号可访问的歌单；情绪音乐陪伴支持关闭，
  不打断已经播放的音乐，不将歌单内容直接当成真实个人经历。
- 从 0.2.17 以来的角色卡导入、AI 固定应用操作、音乐确认续跑与界面改进一并进入源码。
  人设支持粘贴文字和 PNG / JSON 文件，仍可手工修改。

## 安装与版本范围

本次只提供 **Windows x64 免安装 ZIP**。完整解压 `XinYu-Windows-0.2.26.zip`，
运行 `XinYu/xinyu_flutter.exe`，不要仅复制单个 EXE。引擎和依赖随包提供，无需安装 Python。
更新前正常退出旧心隅，在新目录解压后启动；原数据仍在 `%LOCALAPPDATA%\XinYu\data`。
使用应用内备份功能保留需要的内容，快捷方式应指向新目录。

Android 源码已同步，但本次没有重新生成 APK。
[现有 0.2.17 Preview APK](https://github.com/tianhao8687/CompanionMemoryOS/releases/download/xinyu-v0.2.17/XinYu-Android-0.2.17-Preview.apk)
仍保留供下载；它不包含这次歌单修复和后续移动端改进。应用名「心隅·测试」，
包名 `com.xinyu.xinyu_flutter.preview`，Android 7.0+ / ARM64。

## 网易云前置条件

在心隅连接本机网易云，并在网易云中开启 SMTC 系统媒体控制。
Windows 后台点歌还需一次[本机控制通道初始化](NETEASE_CDP_VALIDATION.md#初始化与发布边界)。
首次登录与初始化单独进行，可能需要进入网易云；普通点歌不会重启客户端。
网易云正常退出后，若不带控制参数重新启动，需单独恢复控制通道。

仅连接本机 `127.0.0.1:9223`，核对客户端进程、精确构建和运行时函数指纹。
模型只得到固定音乐操作，不能提交任意 JavaScript、地址、端口或程序路径。
收费歌和试听由官方客户端判断，不绕过权限，也不自动购买。

已适配 Windows x64 构建 `3.1.41.205529`、`3.1.40.205461`、
`3.1.39.205426`、`3.1.38.205386`，以及独立审阅的 3.1.41 热更新资源。
**只有当前 3.1.41 运行时做过完整实机后台播放验收**，其余三个构建仅有安装包契约与离线验证。
未知热更新明确拒绝；并非对这些版本的所有后续热更新作兼容承诺。

## 验证与边界

- Windows 本地全量 Python：1,887 passed / 1 skipped；Ruff、mypy 166 个源文件通过。
- Flutter analyze 与 150 项测试通过，Windows Release 界面重新构建完成。
- 随包引擎通过独立合成数据库的真实进程检查；真实 stdio MCP 验证当前账号和歌单歌曲资料读取。
- 3.1.41 在最小化、托盘状态下验证搜索、播放、暂停、继续和一次切歌；持续记录前台、焦点、
  窗口显示事件及鼠标位置，并核对实际歌曲与进度。详见[执行层验证](NETEASE_CDP_VALIDATION.md)。
- 发布前增加跨平台检查，修复仅 Windows 可用的原生接口类型边界，并隔离测试平台模拟。
  Windows / Linux 类型检查和 175 项音乐回归通过，最新引擎重新打包；
  Flutter 界面沿用同一份已验收的 0.2.26 Release 文件。

这些检查没有调用真实聊天模型，也没有读取日常聊天数据库。实际模型的选歌与措辞仍需体验验收。
AI 使用歌曲信息、歌词和用户分享，没有接收歌曲音频。
收费歌曲已实测按当前账号权限完整播放；无完整权限账号的试听仅有离线分支验证。
进度拖动仍以官方客户端开放的媒体能力为准。
