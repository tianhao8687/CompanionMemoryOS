## Loop 与 MCP 扩展验证

- 多步模型 → 工具 → 观察 → 最终回答流程；步数、工具次数、Token 预算与取消。
- stdio、Streamable HTTP、SSE 三种传输对真实本地 MCP 测试服务完成初始化、发现、调用。
- 参数白名单、JSON Schema 校验、外部引用阻断、待确认审批、配置变更失效、重复调用复用。
- 未知结果不自动重试，启动恢复将执行中操作标为待核对；撤销能力后仍可拒绝待确认项。
- 定时任务持久化、错过任务合并、每日时刻、暂停取消、外部操作到时等待确认。
- 模拟 ADB 验证应用与联系人范围、过期界面、发送控件限制、原草稿保护、中文编码输入，
  以及发送后无法确认结果时返回 uncertain。
- 隔离浏览器实际完成：设置保存、创建提醒、MCP 服务配置与发现、聊天发起工具操作、
  确认执行、查看记录、到时收到通知。桌面与 390px 窄屏布局可用，控制台无错误/警告。

MCP 测试服务只回显参数，没有连接真实手机或微信，也没有向任何联系人发送测试消息。

## 本次覆盖

- 用本地 HTTP 服务实际收发 DeepSeek 兼容请求，核对鉴权头、路径、`max_tokens`、
  模型名与思考模式参数；验证最终文本解析、用量读取和不暴露推理内容。
- 覆盖无 Key、401、402、403、429、500、重定向、截断结果及错误格式。
  错误回复不包含提供商正文或 Key，不自动重试收费请求。
- 验证保存/模型授权、普通陪伴与恋人设定切换、连续聊天、重启恢复、分页历史、
  幂等重投、失败恢复、并发冲突及作用域隔离。
- 验证「以后叫我…」跨对话保存、更正版本链、称呼问题的状态查询、
  旧请求重放不会复活旧名字，以及引述/假设不升级为用户称呼。
- 验证「记住：…」保留原文证据、临时倾听要求与近期疲劳进入已有状态层。
- 验证 Key 不写入设置、导出或数据库；服务重启不保留页面输入的 Key；
  保存的自定义端点不能在重启后继承其他端点的环境变量 Key。
- 浏览器使用独立数据目录和明确的模型替身，完成设置保存、测试连接按钮、发送、
  记忆手札、手机历史菜单、新建对话和刷新恢复。默认应用的数据没有测试聊天。
- 最后恢复桌面视口，关闭测试实例，保留正常应用入口；最终首页控制台无错误或警告。
