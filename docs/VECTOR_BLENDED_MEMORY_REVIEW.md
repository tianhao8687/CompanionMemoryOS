**一个有区分力的失败：已经搜到预算，仍然答不出**

E32 的向量候选里，`预算八十` 排第 9，相似度 0.4232；`奶茶十八` 排第 18，相似度 0.3192。两张卡在请求前均为 active。它们没有进入后续使用计划；入围的卡片愿望、泛化偏好等又被标为 `incidental_ambiguity_should_not_interrupt` 并全部 suppress，最终 `[RELEVANT MEMORY]` 的 evidence 为空、结果为 ambiguous。

这说明需要检查完整的选择过程：有目标的事实被更泛的材料挤掉，随后消歧又清空证据。不能简单把本例归因于“没有开向量”，也不能只放开所有限制。保留对象和关系的完整记忆，例如“给阿遥的礼物预算已改为 80 元”，比孤立的“预算八十”“我的这杯挑对了”“我喜欢那个画面”更有用。

**后续修复优先级**

1. 修好提取协议兼容与可观察的失败处理，减少整轮结果因一个字段非法而被丢弃；保留人物、对象、引用层级和指代关系。
2. 修自然遗忘的目标解析及来源清理，只有实际执行后才能给出相应确认。
3. 让改期、取消、完成同步更新原始事件、关系未完事项与派生记忆，避免多处记录各说各话。
4. 调整混合排序和使用计划，使实际任务所需的金额、人物、时间能进入上下文；不以扩大候选数量或放宽全部边界代替准确选择。
5. 检索不到时承认没有接上，不断言用户从未讲过。E22 已自然提出过这一要求，E32 又重犯，相关沟通偏好也没有可靠地延续。

另有两个旁路问题：E15 的“安静几分钟、别追问”被存成 durable 的“别追问”；E25 明确恢复互动后行为能切回，但存储寿命仍值得修。E22 正确算出余额 23，却又说“还剩一半多”，数值工具正确不能保证后续文字关系正确。这些没有用来给记忆测试虚构一个综合分。
