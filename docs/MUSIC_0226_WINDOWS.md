# Windows 0.2.26+29：网易云歌单读取修复

2026-10-17，用户在 0.2.25 的一起听对话中收到“歌单没连上”的回复。
排查只调用固定的账号、歌单列表和歌曲资料工具，没有切歌、重启网易云或读取日常聊天数据库。

## 根因与修改

0.2.25 打包引擎的真实 MCP 可识别本机账号并取得三份歌单，但旧
`/api/playlist/detail` 返回 HTTP 200、业务码 `20001`，无法取得歌曲。
原应用把这一阶段的失败汇总为未读到歌曲，没有明确告知模型账号已识别。

同一歌单的 `/api/v6/playlist/detail` 返回业务码 200 和歌曲目录。
它可能只附带六首歌曲的完整资料，同时返回全部歌曲 ID。因此改用该固定接口，
按请求的 offset / limit 选择歌曲，只补取这一页缺失的公开歌曲资料，维持原有顺序。
不下载音频，不读取 Cookie，不把未返回的歌曲当作空歌单，不使用其他歌替代。
单页上限仍为 50 首，应用选歌参考仍最多取三份歌单、每份 20 首。

歌单详情读取失败时，应用回执区分账号已识别与歌曲读取失败，并标明失败阶段。
保留旧参考、来源撤回、关闭读取和遗忘规则；歌单取样仍不等于听歌次数或“没听过”的证明。
这次没有修改播放器、窗口控制、Agent 调用循环或真实模型配置。

- `frozen-playlists-result.json`：新包通过真实 stdio MCP 重现相同结果；零播放、零真实模型调用。
