# 聊天操作、阅读位置与角色主页

本轮面向 Windows / Android 的共享 Flutter 界面，保留水润玻璃样式、两端各自的本地数据。
不增加消息重发、重新生成或编辑后重发入口。网络请求失败时原有的同请求重试不变。

## 消息操作

- 手机长按消息、电脑右键消息，可引用回复、复制、收藏、进入多选，也保留保存共同回忆。
- 多选最多 100 条，可按聊天顺序批量复制，或批量收藏。已收藏消息会显示书签。
- 收藏夹在角色主页中；支持取消收藏、复制和查看原消息上下文。图片、表情包随原消息显示。
- 收藏只保存原消息 ID，在同一个 SQLite 中读取原文；不会另存一份聊天内容，也不会因为收藏
  额外写入 AI 记忆。原消息遗忘、撤销来源同意或删除后，收藏失效并清除。

## 聊天节奏

设置 → 消息 → 自然聊天节奏，默认开启。连续发送的纯文字先显示在聊天中，停顿约 1.2 秒后
合成一次模型请求；继续输入会延长等待。可以点“现在回应”马上发送，或“收回到草稿”。
这一组最多 6000 字，底层只保存一次用户输入与一次回复，不增加重复模型调用。
带图片或引用的消息立即发送，关闭节奏选项后所有输入按原来的方式立即发送。

AI 自己生成的空行段落显示为多个相邻气泡，代码、列表等结构保持完整，数据库保留完整原文和
同一个来源 ID。界面不删问题、不改写回复、不强制固定句数；人物设定和当前用户要求优先。
此项改善输入与阅读的节奏，不代表真实模型的语言质量已经验收。

## 阅读位置与草稿

每个会话独立保存草稿、待发图片、引用目标和最近阅读的原消息位置。切换会话、正常关闭重开后恢复；
进程突然结束时，最后约 250 毫秒尚未落盘的输入仍可能丢失。
原引用被遗忘后会清除引用，保留用户自己写下的新草稿；跨会话来源不能作为当前引用。

上翻时右下角出现“回到底部”；有新消息时显示新消息数量。阅读旧记录时新消息不抢位置。
自己点击发送会回到底部一次；等待合并后真正发送时，不再重复跳动。
重新打开后恢复旧位置，不把尚未读到的消息自动标为已读。

这些数据存在原来的 SQLite，遵循本机保存授权。关闭保存授权会清除收藏和界面草稿；
它们不是第二套记忆系统，草稿不进入模型上下文。

## 独立角色主页

点击聊天顶部角色名或任一方头像，打开角色主页。可切换“TA 的主页”和“我的主页”，查看和编辑
双方昵称、人物资料及头像；对方的性格和说话方式沿用已有自定义角色规则。
编辑只写回当前选中的人物字段，其他连接、授权和外观设置保留。

主页还提供收藏夹、我们的手账和聊天记录入口。这里是当前双方的独立资料页面，
不引入云端角色广场、账号同步或多角色数据库。

版本、安装包与验收边界见 [0.2.5 交付记录](ANDROID_025_DELIVERY.md)。
所有自动验收使用独立合成数据，真实模型调用需要另行授权。
