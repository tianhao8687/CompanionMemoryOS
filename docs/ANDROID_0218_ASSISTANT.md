# 心隅 0.2.18：安卓体验与对话配置

本地预览版 `0.2.18-preview`，versionCode 21，沿用 `com.xinyu.xinyu_flutter.preview`
包名及测试签名。现有支持范围为 Android 7.0+ / ARM64，不检测手机品牌或型号。

## 对 AI 说需求

连接支持工具调用的 AI 后，可以说：

- “我想导入人设卡”：自动打开导入页，选择 PNG / JSON / TXT 或粘贴文字，核对后使用。
- “按这段人设设置你……”：内容完整时，AI 可整理角色设定并保存，之后仍可手动逐项修改。
- “我想体验全部功能”：开启自然聊天、表情、回忆小窝、主动陪伴，保留免打扰时间并显示概览。
  音乐与系统通知仍需检查连接/授权；没有自动播放、开始计时或开启其他外部工具权限。
- “帮我连接网易云”：配置并连接已知内置工具，保留已有操作权限，不播放歌曲。
- “字体调大”“关闭主动陪伴”“改成沉稳一些”“撤销刚才的设置”：实际保存设置。
  撤销只恢复本对话中 AI 改过的值，遇到后来手动修改同一字段时保留手动值。
- “打开系统通知授权”“开启媒体控制权限”：可打开系统入口，最终授权由用户完成。

六个 `app_` 工具复用 ToolHub 的校验、幂等与操作回执。设置使用原 `RomanceSettings` 和 SQLite
保存流程，没有新增偏好数据库。关闭外部工具不影响内置配置；仅允许指定的角色、字号和功能开关，
不能修改 Key、模型端点、数据授权、外部工具权限或记忆。工具保存后即使模型回复失败，客户端也核对
真实保存状态。人设中的虚构背景、开场示例不作为既有共同经历插入聊天历史。

## 界面与导入

加号改为带图标的玻璃面板，设置提供人设导入入口。使用已有 Noto Sans SC，正文 400、标题 500，
手机正文 17、说明 14、标题 18 逻辑像素；尊重系统和应用字号。称呼字段使用独立标签，消除浮动标签
与边框、展开区域的裁切。玻璃层次来自透明度、渐变、亮边和少量固定区域模糊。

照片通过系统照片选择器，不支持时使用图库 ACTION_PICK；人设文件和备份保留文件选择器。
依据 [Android Photo Picker](https://developer.android.com/training/data-storage/shared/photo-picker) 的
能力探测实现，读取用户选中的图片，不索取整个图库的广泛权限。

人设支持纯文本、V1 / V2 / V3 常用字段，PNG 读取 `tEXt` 中的 `chara` / `ccv3`。
提取称呼、描述、性格、虚构背景、开场和对话示例；作者说明只在预览展示。
参考 [Character Card V2](https://github.com/malfoyslastname/character-card-spec-v2/blob/main/spec_v2.md)。
不承诺完整酒馆运行时兼容：世界书、扩展、全局指令和额外资源不执行，预览说明未导入部分。
文件最多 20 MB、文本/JSON 最多 256 KB；解析在独立 isolate，嵌套和块数量有界。
超出现有角色字段长度时在预览中精简，不静默截断，失败或取消不覆盖当前人设。

## 性能与验证

聊天气泡不再逐条实时模糊背景；缩略图按显示尺寸和像素密度解码并保持比例。
音乐进度等无关更新不重建聊天阅读区，新增消息比较使用集合。
参考 [Flutter 性能建议](https://docs.flutter.dev/perf/best-practices)。没有机型判断或为某一手机降低画质。

- Ruff、Mypy 通过（154 个 Python 源文件），Flutter analyze 无问题。
- Python 全量运行：1,630 通过、1 跳过、1 个旧工具列表断言失败。
  更新该断言以包含新增内置工具，保留外部能力关闭验证后，相关及新增工具测试共 16 项通过。
  随后补充设置重建后的停止回复验证，工具/交互专项最终 37 项通过，包含 3 个首轮之后新增用例。
  最终测试集 1,635 项，未将首轮失败日志覆盖成成功。
- Flutter 全量 142 项通过；操作名称和大字号检查另跑相关 22 项通过，
  最终输入标签无障碍语义及导入页忙碌状态调整后，相关 28 项通过。
- 脚本模型验证保存、重试、重启、撤销、手动冲突、跨对话隔离、权限范围和回复失败后的状态核对。
