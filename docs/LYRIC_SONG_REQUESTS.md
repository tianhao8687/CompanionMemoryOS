# 歌词点歌：0.2.16（19）

2026-10-15。本次把一句歌词找歌接入现有聊天、MCP 操作账本和「一起听」，
Windows 与 Android 使用同一套歌曲候选。保留原模型配置，没有新增音频模型。

## 用户流程

- 「这句歌词写得真好」继续聊天；「这是什么歌」只搜索；明确要求播放才交给客户端。
- 歌词搜索只发送用户提供的片段，检索类型为 `1006`。忽略大小写、标点和高亮标签后，
  本地核对返回片段是否包含查询；不给模型返回服务提供的整段歌词。
- 同名同歌手同版本的不同专辑收录可以直接选；明显不同版本由模型提供候选供选择。
  搜索排名与片段匹配均不能证明原唱或版权播放权限。
- 歌曲卡片从实际工具回执生成，最多三首。没有封面时用唱片图标；直接点选不再发一轮聊天。
- `requested` 只显示已交给网易云。确认正在播放且歌曲 ID 一致才显示已确认开始播放；
  只有标题、歌手和专辑一致时单独显示信息匹配。失败、未确认不自动反复打开。

## 实现边界

`netease_search_songs` 新增可选 `search_type=song|lyrics`，旧调用继续默认普通歌曲搜索。
固定网易云 HTTPS 兼容接口限制时间、返回大小、候选数和 URL，封面查询失败不丢失歌曲结果。
该接口没有开放平台稳定性承诺，服务变化时可能需要更新适配。

AI 在同一次请求中搜索过歌词后，打开歌曲必须有对应片段匹配证据；随后改搜歌名不能绕过检查。
明确点击卡片可以选择未匹配候选，但 ID 必须来自本次真实结果。会话不一致、源消息已遗忘、
工具停用均拒绝执行。相同点选请求复用原操作，不重放结果不确定的打开动作。
这里的执行检查不能代替真实模型的意图理解验收。

卡片只是现有账本的展示，不新增歌曲偏好库。按钮只确认当前歌曲，保留工具的长期权限。
界面沿用 Noto Sans SC、平台字号和主题色，按钮触控区域至少 48，允许文本换行。
