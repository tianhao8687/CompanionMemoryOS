# 回忆小窝：像素物品画风样稿

`coffee-rocket-v1.png` 是 2026-10-04 在本次开发会话中，用内置 imagegen 工具绘制的
原创透明背景样稿。它表达“咖啡续航的小火箭”这个合成创意，用于讨论正式物品的造型、
像素轮廓、奶油/木色/鼠尾草绿配色和明暗层次。

它不是用户的真实回忆，不是应用当前聊天模型的实测输出，也不是供模型挑选的预制物品库。
应用仍由当前聊天模型自主选材、输出独立的 32×32、最多 16 色像素数据。
样稿的大尺寸 PNG 不等于已经通过该数据格式或像素美感验收。

运行时房间背景位于 `companion_agent/web/nook/sunlit-room-v1.png`；Flutter 打包副本
位于 `clients/xinyu_flutter/assets/nook/`。两端共用同内容的 `room.json` 坐标定义，
由资源一致性测试防止两个版本偏离。房间背景属于固定环境；AI 物品作为独立图层绘制。

用户选定的风格参考：[PixelPortal 的温馨像素房间](https://www.pinterest.com/pin/20195898326699429/)。
项目背景与本样稿均为新生成的原创构图，没有复制或打包该参考图片。

功能与验收记录见 `docs/MEMORY_NOOK_V1.md`。

## 三件样品试摆（2026-10-04）

网页小窝的“看看像素试摆样品”入口打开 `companion_agent/web/nook/samples.html`。
它使用当前房间背景和 `room.json` 的窗台、纪念架、桌面坐标，可点物品或区域拉近，
也可在 100%–170% 之间调整试摆尺寸；初始值 135%。此页面不读写回忆，也不调用模型接口。

三件透明 PNG 的运行时资源保存在 `companion_agent/web/nook/samples/`：

- `daisy-planter-v1.png`：向阳的小雏菊，窗台中间。
- `moon-lamp-v1.png`：晚安月亮灯，纪念架中间。
- `coffee-rocket-v1.png`：咖啡小火箭，桌面中间；复用此前的原创样稿。

本次新增两张由内置 imagegen 生成的图片，完整生成提示词仅保留在本地，不随仓库发布。
绘制时根据 PNG 的透明边缘定位物品底部，不修改原始图片。
这些大尺寸 PNG 用来观察画风，不代表当前聊天模型的 32×32 像素输出已经达到同等效果。

按本轮要求只观察了页面显示、物品近景和尺寸调整，没有再次运行全套回归。
预览截图保存在 `.agent-tests/nook-samples-20261004/`。
